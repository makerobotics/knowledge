# Knowledge Notes

A small collection of practical notes and references for software development, AI agents, and everyday tooling. The documents are concise reminders rather than a packaged application, so there is nothing to install or build.

## Contents

- [AI and agent workflows](AI.md) — notes on using Copilot agents and skills.
- [Development tools](tools.md) — references for Git, Python, SSH, uv, and Visual Studio Code.
- [Linux](linux.md) — a place for Linux notes; content is still to be added.

## Getting started

Open a topic above and browse the relevant notes. You can also clone the repository and read the Markdown files with any text editor:

```sh
git clone <repository-url>
cd <repository-directory>
```

Replace the placeholders with this repository's URL and local directory name.

## Help

These notes do not define a separate support channel. For an unclear or outdated entry, check the linked reference where available, or suggest a correction through the repository's hosting platform.

## Contributing

Contributions that keep the notes accurate, concise, and easy to scan are welcome. Add information to the relevant topic file, use links to authoritative sources when helpful, and avoid duplicating existing notes. No contribution guide or maintainer contact is currently provided.
